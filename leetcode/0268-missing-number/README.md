## Problem Statement

## Constraints

- <code>n == nums.length</code>
- <code>1 &lt;= n &lt;= 10<sup>4</sup></code>
- <code>0 &lt;= nums[i] &lt;= n</code>
- All the numbers of <code>nums</code> are <strong>unique</strong>.

## Solution

```py
class Solution(object):
    def missingNumber(self, nums):
        """
        :type nums: List[int]
        :rtype: int
        """
        s=sum(nums)
        n=len(nums)
        total=n*(n+1)//2
        return total-s
```
